# skills-introduction-to-github
Exercise: Introduction to GitHub
🎉 This PR serves as a summary of my first GitHub learning journey. Here are the core concepts I've mastered:

Repository (仓库): The central folder that contains all project files and version history.

Branch (分支): A parallel "draft" space to safely make changes without affecting the main project.

Commit (提交): A "save point" or snapshot of the modifications made to files.

Pull Request (PR - 拉取请求): A proposal to merge my changes from a branch into the main branch for review.

Merge (合并): The final step to officially integrate the branch's changes into the main timeline.

Successfully completed my first workflow! 🚀

sch:
借此机会总结一下我刚刚学到的 GitHub 核心概念：

仓库 (Repository)：存放项目所有文件和版本历史的核心文件夹。

分支 (Branch)：一个平行开发的“草稿箱”，可以在不影响主分支的情况下安全地修改代码。

提交 (Commit)：对文件修改的“存档”或“快照”，记录下每一次更改。

拉取请求 (Pull Request)：相当于“交作业”，请求将自己的分支修改合并到主分支，方便他人审查和讨论。

合并 (Merge)：将分支上的修改正式纳入主分支的最终步骤。

顺利完成第一次全流程操作！🚀
